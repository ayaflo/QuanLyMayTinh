# QUY TẮC CỐT LÕI
- **Think Before Coding:** Nêu rõ các giả định và làm rõ sự mơ hồ trước khi code.
- **Simplicity First:** Chỉ viết code tối thiểu vừa đủ giải quyết bài toán tuần hiện tại.
- **Surgical Changes:** Chỉ sửa đúng vị trí cần sửa, không sửa lan man các file khác.
- **Goal-Driven Execution:** Xác định rõ tiêu chí hoàn thành trước khi viết code.
