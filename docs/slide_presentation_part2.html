BẢO MẬT CẤP CAO (F5)

Mã Hóa AES-256-GCM & Triệt Tiêu Lỗ Hổng IDOR

Bảo vệ tính toàn vẹn dữ liệu tĩnh và ngăn chặn cha mẹ A điều khiển máy con B

🔐 Mã Hóa Dữ Liệu Tĩnh AES-256-GCM AEAD
  • Nonce ngẫu nhiên 12 bytes + Auth Tag 16 bytes.
  • Vừa bảo mật nội dung, vừa xác thực tính toàn vẹn.
  • Nếu cơ sở dữ liệu bị sửa đổi dù 1 bit ➜ Ném ngoại lệ InvalidTag và từ chối nạp.
🛡️ Triệt Tiêu 100% Lỗ Hổng IDOR
  • Mọi API nhận device_id (Lệnh khóa, Sửa luật, Xem báo cáo) đều kiểm tra:
  • assert device.parent_id == current_parent.id
  • Phụ huynh A can thiệp thiết bị Phụ huynh B ➜ Phản hồi HTTP 403 Forbidden ngay lập tức.
